# Trajets HDF V2.11 — Vue graphique du roulement

Cliquer sur un numéro de train dans Départs / Arrivées ou dans un itinéraire
ouvre le graphique Orcades et indique la ou les journées de service (JS)
correspondantes.

La page du roulement est automatiquement centrée sur la JS et la ligne est
surlignée. Si un train apparaît dans plusieurs variantes, des onglets permettent
de passer d'une JS à l'autre.

Le fichier intégré est « MRA multiples », valable du 31/08/2026 au 12/12/2026.
Les numéros avec préfixe S/R, suffixe UM et formes `xxxxxx/x` sont normalisés
pour la recherche.
