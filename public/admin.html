Import autonome : le PDF est analysé dans ton navigateur. Les 7xxxxx sont traités comme W, les 6xxxxx et 9xxxxx comme EVO. Pour les EVO, le sens est lu dans l'ordre vertical des libellés du graphique (haut → bas). Les mouvements dont le sens ou l'heure ne peuvent pas être déterminés avec assez de confiance sont laissés en anomalie plutôt que d'être inventés.
